Shop Floor Reference Cards

One half-page card per terminal – print on card stock, cut along the dashed line, laminate. Every card follows the same shape: sign in, run the screen, end of shift, and a reminder to tap the ? icon for more detail on that exact screen.

  • 1. File → Print · Letter · 100% scale · no margins
  • 2. Cut each sheet along the dashed line
  • 3. Laminate, trim to the card border
Sheet 1 of 4
Die Cast Open · Record · Release
Run the screen
  • 1Check the Die box names the tool actually mounted on this machine.
  • 2On Open Basket: pick the Part, scan the LTT, press OPEN BASKETS.
  • 3On Record Shift Output: pick your shift, enter the shot count, Compute / Preview, log any scrap, SUBMIT SHIFT OUTPUT.
  • 4On Lot Release: press Release on any basket that is full.
If the die is wrong or empty – stop and tell a supervisor. Do not work around it.

End of Shift Go to End of Shift. Tap every break you took, then Submit Shift Time Entry.
Trim Check IN · Trim OUT
Run the screen
  • 1If this press is shared, pick it from the top of the screen first.
  • 2On Check IN: scan the LTT, review the LOT shown, press Move.
  • 3On Trim OUT: tap the LOT’s card (or scan its LTT), enter the Lot count.
  • 4Add scrap reasons if any, then press Trim OUT to release the whole LOT.
Trim OUT always moves the entire LOT together – there is no split here.

Machining IN Scan · Confirm
Run the screen
  • 1Scan the LTT on the casting you picked up.
  • 2Check the LOT, item, and piece count shown are the right ones.
  • 3Press Start Machining. It moves onto Active machined LOT below.
You do not have to type which line or cell you are on – the scan already knows.

Machining OUT Mint from the queue
Run the screen
  • 1The oldest casting is already selected. Tap Select only to work a different one.
  • 2Enter how many Pieces to mint – it pulls from the whole queue, not just one casting.
  • 3Add scrap lines if any, then press Submit.
If the queue is short, you will be asked to confirm minting the smaller amount – that is normal, not an error.

Assembly · Non-Serialized Fill · Complete
Run the screen
  • 1Check Now producing and the components staged at this cell.
  • 2By Count lines: enter the count and press Complete Tray when full. By Weight / By Vision: the scale or camera closes it – nothing to press.
  • 3On a By Count line, once enough trays are in, press Complete under Container Completion Gate.
A single-tray container ships on its own – you will not see the gate for it.
