Shop Floor Reference Cards

One half-page card per screen – print on card stock, cut along the dashed line, laminate. Screens that run in more than one mode get a card each, so a card never asks the operator to hold two tabs in their head at once. Every card follows the same shape: sign in, run the screen, report downtime, and a reminder to tap the ? icon for more detail on that exact screen.

  • 1. File → Print · Letter · 100% scale · no margins
  • 2. Cut each sheet along the dashed line
  • 3. Laminate, trim to the card border

Die CastOpen Basket One basket per cavity
Run the screen
  • 1Check the Die box names the tool actually mounted on this machine – the cavity rows below come from it.
  • 2On each cavity row, pick the Part. Every cavity running the same part? Press Copy part to empty rows.

  • 4Press OPEN BASKETS to open every row you filled in.

DowntimeDowntime Entry Start · Reason · End
Run the screen
  • 1Check the Machine box at the top is the one that stopped; pick it from the list if not.
  • 2Press Start Downtime as soon as it stops – do not wait until you know why. It opens with no reason.
  • 3Pick the Reason on the row once you know it.
  • 4Press End on the row when work resumes. No supervisor sign-in needed.
Add Past Event logs downtime you missed. Edit and Void both ask for a supervisor sign-in – Void is permanent.
